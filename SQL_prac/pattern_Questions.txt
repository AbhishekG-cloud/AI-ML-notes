REGEXP
=================================================================
Pattern               Meaning                          Example
^A                    Starts with A                     Agra
a$                    Ends with a                       Patna
^A.*a$                Starts with A, ends with a        Agra
^[aeiou]              Starts with a vowel               Agra
[aeiou]$              Ends with a vowel                 Pune
^[aeiou].*[aeiou]$    Starts and ends with a vowel      Agra
^[^aeiou]             Does not start with a vowel       Delhi
[0-9]                 Contains a digit                  City7
.                     Any single character              Aga
.*                    Zero or more characters           Any string
===================================================================
SELECT CITY
FROM STATION
WHERE CITY REGEXP '^A';
=================================================================
select distinct(CITY)
from STATION 
where CITY REGEXP  "^[aeiou]"

## INDEX IN SQL
Query the Name of any student in STUDENTS who scored higher than  Marks. 
Order your output by the last three characters of each name. 
If two or more students both have names ending in the same 
last three characters (i.e.: Bobby, Robby, etc.), secondary sort them by ascending ID.

SELECT Name
from STUDENTS
where Marks > 75
order by right(Name,3),ID ASC
